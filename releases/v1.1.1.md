# NodeWatch v1.1.1 — Cross-Platform Dashboard Simulator

**Patch release** · 19 October 2026 · Updates [v1.1.0](https://github.com/harrydavies1/NodeWatch/releases/tag/v1.1.0)

This small release adds a way to **preview the real NodeWatch Raspberry Pi dashboard on macOS, Windows or desktop Linux** using **Python and Tkinter**, without configuring any server, Raspberry Pi, disks, SSH keys or monitoring agent.

## Added in v1.1.1

- **Same GUI, simulated telemetry:** `python-display/simulate.py` uses NodeWatch's **existing Tkinter dashboard drawing code**, not a redesigned imitation. Clearly marked **SIMULATION / FAKE DATA** values change over time.
- **Four-page preview by default:** System Overview, Network & Services, NAS Storage and HDD Temperatures, including fake temperature warnings.
- **Flexible previews:** choose `--pages 2`, `--pages 3`, `--pages 4` (default), or `--pi-mode` to preview the two-page Pi-only view.
- **Same navigation as Raspberry Pi:** click/tap the left or right half, press Left/Right or Space, and press Escape to quit.
- **Optional automatic page rotation:** `--auto-rotate`, `--rotate-seconds 8`, plus `--refresh-seconds`; auto-rotation is off by default for easier demonstrations.
- **Windowed or fullscreen:** default 480×320 preview, or `--fullscreen`.
- **No additional pip packages:** the simulator uses Python 3 standard-library modules and Tkinter only, **provided Tkinter is installed**. It does not import the real telemetry backend, load secrets/configuration or contact your server.

## Run it on your Mac

Clone the public repository or update your existing checkout:

```bash
git clone https://github.com/harrydavies1/NodeWatch.git
cd NodeWatch
python3 -m tkinter
python3 python-display/simulate.py
```

On an existing checkout, use `git pull --ff-only` instead of cloning. The `python3 -m tkinter` test should open a small Tkinter window; close it before starting the simulator.

Run with auto-rotation:

```bash
python3 python-display/simulate.py --auto-rotate --rotate-seconds 8
```

Preview fullscreen:

```bash
python3 python-display/simulate.py --fullscreen
```

On Windows, the equivalent launcher is often `py python-display/simulate.py`. On Ubuntu/Debian install `python3-tk` if missing. **A graphical desktop is required**; headless Python cannot display Tkinter windows. The simulator is not a standalone single-file download: it needs the sibling NodeWatch display/helper source files from the same repository.

## Compatibility and testing

- **No behaviour change to live NodeWatch monitoring:** the production GUI still uses the original `dashboard.collect_state()` when no simulator collector is passed.
- v1.1.0's HDD-temperature support, NAS monitoring, Ubuntu agent, Pi Mode/Server Mode, touchscreen navigation, rotation settings, Tailscale and other host services are unaffected.
- Simulator data is intentionally **fake**. It does not inspect real disk temperatures, CPU usage, network traffic or machine identity.
- Added automated tests for state shape, two/three/four-page selection, Pi-only preview, simulated refresh variation, CLI switches and `--help` without third-party packages. The **GitHub Actions release workflow verifies syntax and the test suite before publishing**.
- The GUI uses the **same Tkinter canvas rendering code** as the Pi. Native fonts can vary slightly between operating systems. No claim is made that every macOS/Python/Tcl-Tk combination has been physically tested.
