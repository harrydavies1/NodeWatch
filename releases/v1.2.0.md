# NodeWatch v1.2.0 — Windows XP Theme + Cross-Platform Simulator

**Stable release** · 22 October 2026 · Builds on [v1.1.0](https://github.com/harrydavies1/NodeWatch/releases/tag/v1.1.0)

This release makes **classic Windows XP-inspired NodeWatch** available as an **optional** theme without changing the original dark dashboard. It also includes the cross-platform offline simulator developed after v1.1.0. The planned v1.1.1 simulator update was documented in the repository but **not published as a GitHub Release**; v1.2.0 is the next stable GitHub release after v1.1.0 and includes those changes.

## New: optional Windows XP-inspired theme

- Choose `DASHBOARD_THEME=xp` on the **Raspberry Pi or desktop displaying NodeWatch**, or launch the live app with `--theme xp`. The existing `dark` theme **remains the default** for existing installations.
- Classic Luna-era blue title bar, blue taskbar with page name and clock, pale raised panels and segmented blue progress bars. Rendered directly using original Tkinter vector shapes, **without bundled Windows wallpaper, licensed Microsoft artwork, browsers or extra Python packages**.
- Maintains all available NodeWatch pages: **System Overview**, **Network & Services**, optional **NAS Storage** and optional **HDD Temperatures**.
- Refined from real 480×320 previews: smaller, better-spaced system statistics and labels prevent crowding on page 1; the unnecessary disk-temperature footer on the HDD page was removed.
- **No Start button or pop-up Start menu** in the final version. Left/right touch areas, keyboard navigation, optional page rotation and XP-style window controls remain available.

## Also included since v1.1.0: cross-platform simulator

- Preview the **same native Tkinter GUI** on **macOS, Windows or desktop Linux** using animated, clearly marked **SIMULATION / FAKE DATA**.
- Launch via `python3 python-display/simulate.py` (dark default) or `python3 python-display/simulate.py --theme xp`; choose 2/3/4 pages, Pi-only mode, fullscreen and optional timed page switching.
- Simulator requires **Python 3, Tkinter and a desktop session** but **not** a running server, agent, network connection, `.env`, `psutil` or `python-dotenv`.
- The simulator is optional: the **normal app continues to show real Pi/Ubuntu metrics**. Start the real monitoring dashboard with `bash python-display/start-native.sh` (Pi fullscreen), or `bash python-display/start-native.sh --windowed --theme xp` (desktop).

## Upgrade an existing Raspberry Pi installation

From your existing **Raspberry Pi** checkout (do not clone over it):

```bash
cd ~/pi-server-dashboard
git pull --ff-only
nano .env
```

For the XP theme, add or edit:

```ini
DASHBOARD_THEME=xp
```

Keep the existing `REMOTE_AGENT_URL` and `REMOTE_AGENT_TOKEN` so **live server metrics** continue working. For the original dark theme, use `DASHBOARD_THEME=dark` or omit the option. Restart the Pi dashboard; if your graphical desktop is configured to automatically start NodeWatch, rebooting is a simple way to load the new appearance:

```bash
sudo reboot
```

**Automatic startup:** existing [desktop-autostart configuration](../docs/AUTOSTART.md) continues working. The startup launcher reads `.env` from the **display device**, so XP starts automatically when `DASHBOARD_THEME=xp` is set and desktop login is active. No second autostart entry is needed. If you run the original dark app simultaneously, close the old process/duplicate launcher.

**No Ubuntu Server changes required for this theme.** The authenticated agent API, HDD SMART collector, Samba NAS storage paths, Minecraft services, Tailscale and existing service settings are unchanged.

## Run the new theme on Mac with real server data

Inside your NodeWatch checkout, keep your existing Mac `.env` values for `REMOTE_AGENT_URL` and `REMOTE_AGENT_TOKEN`, then run:

```bash
git pull --ff-only
bash python-display/start-native.sh --windowed --theme xp
```

For the original design:

```bash
bash python-display/start-native.sh --windowed --theme dark
```

If Git refuses to pull because of local theme edits, preserve them before updating:

```bash
git stash push -m "Backup local XP theme" -- python-display/xp_theme.py
git pull --ff-only
```

Do **not** apply the old stash on top of the new theme unless you intentionally want to restore those local edits. A `401 Unauthorized` response means the display-side `REMOTE_AGENT_TOKEN` does not match the server-side `AGENT_TOKEN`, not a theme bug; keep tokens private.

## Verification

- **Confirmed by the project owner on 22 October 2026:** XP theme works on the project's actual Raspberry Pi display with live server stats. The theme also ran with real Ubuntu server telemetry on Mac.
- **59 automated tests passed** on GitHub Actions before publishing, including headless XP-theme regression checks, simulator/telemetry tests, agent integration, Python syntax and shell syntax.
- Tested hardware: Raspberry Pi 3 Model B with a 3.5-inch OSOYOO SPI RPi Display V1.0, monitoring a Dell OptiPlex running Ubuntu Server. Other desktop environments, drivers and SPI hardware may render system fonts slightly differently.
- No firmware, operating-system, NAS partition, agent, firewall, or server autostart changes are part of this release.
